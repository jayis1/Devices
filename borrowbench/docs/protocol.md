# Wire protocol

Schema v1 envelope: `{v:1,id:string,seq:uint32,kind:string,ts_ms:uint64,payload:object}`. Event kinds: `presence` (boolean advisory), `weight` (integer grams, calibrated status required), `inspection` (only emitted after local human button press). Payload limit 128 bytes on node framing and 512 bytes at HTTP ingest. Invalid schema/version/range is rejected; duplicate `(id,seq)` is acknowledged idempotently. The timestamp is informational and untrusted until synchronized. Persist monotonic sequence counters across resets in production; current firmware examples do not implement persistence, encryption, replay defense, or BLE. Provision by physical operator action; production transport must use BLE LE Secure Connections with unique credentials. Never put names or credentials in payloads.
