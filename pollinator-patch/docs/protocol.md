# Protocol v1

Transport-independent, little-endian frame: `magic[2] = 0x50 0x50`, `version:u8=1`, `type:u8`, `node_id:u16`, `sequence:u16`, `payload_len:u16`, `payload[payload_len]`, `crc16:u16`. CRC-16/CCITT-FALSE covers header and payload; CRC detects accidental corruption and is not authentication. Maximum payload 64 bytes; total frame 76 bytes. Reject unknown versions/types, oversized/truncated frames and invalid CRC. Sequence wraps modulo 65536; receivers should reject duplicate sequence numbers within a short replay window. Prototype code does not implement replay state or cryptographic authentication.

Message types: 1 bed sample; 2 volunteer bloom observation; 3 gateway acknowledgement. Sample payload is signed temperature in centi-degrees C (int16 LE), moisture ADC raw (uint16 LE), battery mV (uint16 LE). Bloom payload: bed ID (uint8), category (uint8: 0 unknown, 1 no visible bloom, 2 some bloom, 3 abundant bloom), observation age seconds (uint16). This compact prototype payload is documented but not yet serialized by node application code. BLE bonding and authenticated MQTT TLS are deployment requirements, not implemented security features. No individual identity belongs in telemetry.
