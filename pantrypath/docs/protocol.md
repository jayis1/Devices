# Wire protocol v1

All integers little-endian. Frame: version:u8, node:u8, type:u8, sequence:u8, epoch seconds:u32, payload length:u8, payload (0–32 bytes), CRC-16/CCITT-FALSE:u16 (poly 0x1021, init 0xffff, no reflection, xorout 0). Max frame 43 bytes. Type 1: shelf delta signed grams int16. Type 2: fridge centi-degrees int16 + door bool. Type 3: volunteer-confirmed category:u8, quantity:u16, date epoch:u32. Sequence is per-node modulo 256; reject duplicates/older-than-half-range. CRC detects accidental corruption, not malicious modification. Authenticated provisioning, acknowledgements, key rotation and MQTT ACLs are production requirements, not implemented. Suggested radio retry: max 3 with randomized 1–3 s backoff. Hub time is authoritative; UI must show observation age.
