# Event protocol v1

Transport: BLE GATT with authenticated bonded peers; gateway may forward events to MQTT over TLS. Application values are integers in fixed units, little-endian on the wire; maximum payload 96 bytes. Envelope fields: version, kind, payload length, device ID, monotonic sequence, uptime seconds, two signed values, CRC-16. Weight uses mg; climate uses milli-degrees Celsius and milli-percent RH; door uses 0/1. Reject unknown versions, invalid lengths, non-monotonic sequence, out-of-range values, failed CRC, and unpaired devices. Duplicate sequence numbers are idempotent. Reconnect uses bounded exponential retry; no remote actuator commands exist. CRC detects corruption only and is not authentication. This document describes a proposed envelope; current C file is a scaffold, not a complete serializer/parser.
