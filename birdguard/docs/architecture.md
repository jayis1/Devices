# Architecture

Two ESP32-C3 sensor nodes publish observations over BLE advertisements to a Raspberry Pi gateway. A local FastAPI service validates and persists JSON records in SQLite. React Native client reads status; internet is optional and no cloud service is implemented. No actuator path exists. Outdoor weather node should be shaded, ventilated, and sheltered from precipitation. Window node observes removable marker-panel presence and ambient light only. Keep gateway and API on trusted LAN; current prototype has no authentication or TLS. Threats include forged/replayed radio packets, unauthorized local API writes, sensor drift, node removal, and gateway loss. Mitigate for prototype by local-only binding and manual inspection; production requires authenticated provisioning, encrypted transport, replay defenses, access control, secure updates, retention controls, and reviewed mounting/electrical design.
