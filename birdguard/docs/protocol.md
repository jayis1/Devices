# Observation protocol v1

JSON over local HTTP after gateway receipt. Required fields: `version` integer 1; `device_id` provisioned string; `seq` unsigned monotonic counter; `ts` UTC RFC3339; `kind` one of `window`, `weather`; `values` object. Window values: `panel_present` boolean, `lux` finite 0–200000. Weather values: `temperature_c` -40–85, `humidity_pct` 0–100, `pressure_hpa` 300–1200, `lux` 0–200000. Unknown keys ignored; invalid types/ranges rejected. BLE prototype encodes the same measurements conceptually; radio framing/driver is not implemented. Production must use authenticated encryption, replay window, length bounds, identity provisioning and key revocation. Example: `{"version":1,"device_id":"win-01","seq":17,"ts":"2026-06-01T12:00:00Z","kind":"window","values":{"panel_present":true,"lux":320}}`.
