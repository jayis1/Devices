# ParkKeys protocol v1

Event envelope: `v` integer 1; `event_id` UUID string; `node_id` provisioned identifier; `seq` nonnegative monotonic integer; `observed_at` UTC ISO-8601; `kind` one of `piano_report`, `cover_state`, `weather`; `value` kind-specific object. MQTT topic `parkkeys/v1/{site_id}/{node_id}/events`, QoS 1, non-retained. Broker ACLs must restrict each credential to its own node topic. TLS and credential rotation are deployment requirements; CRC is not authentication. Backend deduplicates event IDs and rejects unknown nodes, oversized payloads, unsupported versions, invalid enums, and non-monotonic sequence values. Reconnect retries use bounded exponential backoff. On clock uncertainty, backend receipt time takes precedence. No remote commands or actuators are defined.
