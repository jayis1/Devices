# Calibration procedure

For each cluster: record unloaded readings for 60 seconds per seat, then apply a repeatable 5 kg test load at the center for 60 seconds; select a threshold with margin between distributions. If distributions overlap, reject the sensor/mount. Remove load and confirm recovery. Repeat 100 load/unload cycles; log drift. This is a prototype procedure, not certified occupancy measurement. Doorway count calibration requires supervised known-direction passages and privacy review; disable it if missed/double events exceed locally agreed tolerance.
