# Protocol v1

Portable codec frame (little-endian): version u8 (=1), node-ID length u8 (1..15), UTF-8 node ID, sequence u32, uptime_ms u32, kind u8 (1=wheel deviation mg, 2=fixture force N milli-units, 3=pressure kPa milli-units), signed value i32 milli-units. Maximum encoded frame is 30 bytes. Reject unknown version, malformed lengths, empty IDs; receiver should deduplicate by node ID+sequence and detect sequence gaps. Sequence wraps modulo 2^32; uptime is not wall-clock time. No acknowledgement/retry behavior is implemented by codec. Intended transport: BLE GATT notifications with bounded reconnect/backoff; MQTT topic `spokesense/v1/{site}/{node}/telemetry` after hub commissioning. BLE security, device provisioning, OTA, broker authentication/TLS, ACLs, timestamps, and replay prevention are not implemented; do not use outside a trusted bench network. Never send actuator commands: protocol is telemetry only.
