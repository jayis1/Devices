# WellSync Schematics

These KiCad-style `.sch` placeholders capture the architectural nets, rails, buses, and critical parts for each node.

- `hub/hub.sch` — CM4 gateway, RP2040 supervisor, LTE and radio.
- `inline-water-quality/inline-water-quality.sch` — chemistry front ends and isolated sensing.
- `pump-controller/pump-controller.sch` — pump contactor, current sensing, pressure loop.
- `tap-sentinel/tap-sentinel.sch` — point-of-use service and treatment verification.
- `weather-sentinel/weather-sentinel.sch` — rainfall, soil, and solar telemetry node.
