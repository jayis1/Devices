# Protocol v1

Envelope fields: v=1; node is unique site-local ASCII ID (1–48 chars); seq uint32 increments per boot; uptime_ms uint32 monotonic; kind entry|approach; valid boolean. Entry requires door_open and staff_check booleans. Approach requires clearance_mm integer 0–5000. UTF-8 JSON capped at 512 bytes. Reject unknown version, malformed values, duplicate/reordered seq (wrap-safe comparison in deployed firmware), and stale samples after 120 seconds using receiver monotonic time. Retries use same sequence and are idempotent; no command messages exist. This prototype's API checks duplicates but lacks wrap-aware and age handling; no production security is implemented. BLE authenticated pairing/encryption and per-device identity are deployment requirements. CRC alone is not authentication.
