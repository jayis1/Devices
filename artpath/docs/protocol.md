# ArtPath local protocol v1

Transport: BLE GATT, binary envelope with UTF-8 JSON payload, max 512 bytes total. Envelope bytes are version (1), type (1), sequence (4, big endian), event ID (16), payload length (2, big endian), payload, CRC-16/CCITT-FALSE (2, big endian, over all preceding bytes). JSON payload uses `node_id`, `event_id` as 32 lowercase hex characters and the application fields below. Receivers reject unknown versions/types, malformed UTF-8/JSON, oversized values and duplicate event IDs. Retries reuse event_id; gateway retains the last 256 ids per node. There is no clock-dependent actuation or command channel. Firmware C helpers validate envelope/CRC; actual BLE serialization and authenticated pairing are not implemented.

Telemetry example: `{"v":1,"type":"ready","node_id":"art-01","seq":12,"event_id":"00112233445566778899aabbccddeeff","content_rev":"2026-01","faults":[]}`. Context node uses `type:"context"`, `temp_c` finite -40..85 and `rh_pct` finite 0..100. Values outside limits are rejected, not clamped. Timestamps are gateway receive time in UTC; nodes need not have a clock.

Content is separate, bounded chunks (max 4 KiB each) keyed by immutable content id and revision. Manifest fields: `title`, `language` (BCP-47), `plain_text`, `transcript`, `audio_path`, `sha256`, `license`, `credit`, `approved_by`, `revision`. Audio checksums are verified before playback. Audio/text remain cached locally. No visitor identifiers or audio capture.

BLE pairing/provisioning must be performed physically by an installer; prototype firmware does not implement authentication. Do not deploy over an untrusted radio environment until authenticated BLE bonding, secure boot, signed content manifests, key rotation and revocation are implemented and tested. Internet sync, if enabled in a future deployment, must use HTTPS/TLS with operator-managed credentials. No MQTT broker is present in this MVP. BLE loss leaves local content usable; gateway loss leaves cached station content usable. No automatic update mechanism is implemented.
