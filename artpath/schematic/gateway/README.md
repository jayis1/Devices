# Gateway electrical and installation notes

Gateway is a Raspberry Pi Zero 2 W single-board computer powered from an external listed 5 V SELV USB supply. No custom carrier schematic is supplied; the BOM is the gateway assembly, not a fabricated board. BLE and Wi-Fi coexistence, antenna placement, enclosure thermal management, and USB supply compliance must be checked for the chosen installation. Do not place gateway where it blocks an accessible route. Keep software on loopback until authentication and TLS are implemented.
