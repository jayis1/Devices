# Architecture and failure behavior
Two sensor node types report small aggregate measurements over BLE to an ESP32-S3 hub. The hub displays status locally, queues a bounded recent event buffer, and forwards to a backend over TLS MQTT (adapter not implemented). Backend REST endpoint accepts validated readings for local demonstration. No cloud command path exists. On node loss, mark data unknown after configured freshness window; on hub/network outage preserve local display and bounded queue; on sensor fault flag status; duplicates are discarded. Load-cell calibration drift and ToF occlusion require onsite human inspection. No actuators. Enclosure, RF, ESD, and battery safety require engineering validation.
