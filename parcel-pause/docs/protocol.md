# Protocol v1
20-byte little-endian frame: version:u8=1, type:u8 (1 doorway, 2 shelf), node_id:u32, sequence:u32, age_ms:u32, value:u16, status:u8, reserved:u8=0, CRC-16/CCITT-FALSE:u16 over bytes 0..17. `value` is a bounded anonymous event/load unit; site configuration defines interpretation. Reject malformed length/version/type/reserved/CRC. Sequence deduplication is modulo 2^32; reject repeated sequence, stale age, and out-of-order reports at gateway. BLE advertising is unencrypted prototype transport; do not deploy sensitive locations without pairing/encryption and threat review. CRC is not authentication.
