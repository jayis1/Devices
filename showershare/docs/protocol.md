# Protocol v1

UTF-8 JSON object, max 512 bytes: `{ "v":1, "node":"stall-01", "seq":7, "ts":0, "kind":"door", "value":0, "unit":"bool" }`. `seq` is unsigned increasing per node; receiver rejects duplicate or lower sequence numbers. `ts` is Unix seconds or 0 when clock is unset. Allowed kinds: `door`, `presence_band`, `surface_temp`, `flow_pulses`, `health`; bounded numeric values only. Units are `bool`, `band`, `C`, `count`, `code`. Never include names or raw load-cell readings. Unknown version/kind, oversized or malformed payloads are rejected. MQTT topic `showershare/v1/{site}/{node}/telemetry`, QoS 1, non-retained. TLS and topic ACLs mandatory for deployment. This document describes the intended wire contract; prototype does not yet implement a complete authenticated radio transport.
