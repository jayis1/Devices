# OutageSync Schematics

These KiCad-compatible placeholder `.sch` files document major silicon, buses, and power domains for each node:

- `hub/hub.sch`
- `panel-controller/panel-controller.sch`
- `cold-chain-tag/cold-chain-tag.sch`
- `outlet-node/outlet-node.sch`
- `fuel-sentinel/fuel-sentinel.sch`

The files are intentionally text-based and lightweight for repo review. They capture board intent, power rails, and major interconnects so a hardware engineer can convert them into full KiCad projects.
