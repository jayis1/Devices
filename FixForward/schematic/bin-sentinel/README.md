# Bin sentinel connection ledger (not a KiCad schematic)
ESP32-C3 3V3/GND; GPIO8 SDA and GPIO9 SCL with 4.7k pullups; VL53L0X at 0x29 and TMP117 at 0x48, both 3V3-compatible. GPIO4 button to GND with internal pull-up. USB 5V to module carrier regulator. UART0 GPIO20/21 debug. Check sensor breakout pullups/address and ToF optical geometry before assembly.
