# Protocol v1

Transport: BLE GATT, gateway central. Characteristic carries UTF-8 JSON for debuggability (production should use bounded CBOR). Maximum 256 bytes. Every report: `v` (1), `node` (provisioned 8-hex ID), `seq` (uint32 monotonic modulo), `ts` (UTC seconds or null), `kind`, `data`, `mac` (HMAC-SHA256 truncated to 16 bytes, hex; per-node provisioned key). Gateway rejects unknown identity, bad MAC, duplicate sequence, malformed bounds, and timestamps >60 seconds old when timestamp exists. Provision keys out-of-band; no shared source-code secret. Key rotation requires local physical enrollment and revocation.

Kinds: `room` data `{lux:0..120000,temp_c:-40..85,rh:0..100}`; `outdoor` same plus `{rain:bool}`; `shade` `{position_pct:0..100,fault:enum}`; `set_shade` `{position_pct:0..100,expires_s:10}`. Command sequence and expiry are mandatory; node rejects expired/replayed commands and enforces local travel/time limits. Acknowledgment includes command sequence and accepted/rejected reason. No retained MQTT actuator messages. Gateway bridges only validated reports to `daylightsync/<site>/<node>/telemetry` over TLS with certificate verification; broker ACL restricts each gateway to its site. This implementation is a protocol reference, not a production security certification.
