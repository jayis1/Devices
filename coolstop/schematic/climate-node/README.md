# Climate node net specification

ESP32-C3-MINI-1 carrier powered from 5V USB, 3V3 logic, common GND. GPIO4 SDA and GPIO5 SCL connect SHT31-DIS-B at address 0x44, with pull-ups to 3V3 and local decoupling per Sensirion datasheet. Firmware currently names these pins. Follow Espressif antenna keep-out and module reference design. Not a native schematic.
