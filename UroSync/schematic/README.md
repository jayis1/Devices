# UroSync Schematics

These are starter KiCad-style schematic text sheets capturing the major power rails, ICs, and interfaces for each hardware node:
- `hub/hub.sch`
- `toilet-dock/toilet-dock.sch`
- `night-mat/night-mat.sch`
- `bottle-tag/bottle-tag.sch`
- `bath-sentinel/bath-sentinel.sch`

Each sheet is concise by design so it can be redrawn into a complete KiCad project with footprints, net labels, and layout constraints.
