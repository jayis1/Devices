# UroSync ML Pipeline

Training utilities for the six initial model families:
- `train_hydrocast.py`
- `train_utiwatch.py`
- `train_nocturia_trend.py`
- `train_nightsafe.py`
- `train_stoneshield.py`
- `train_nudgebandit.py`

All scripts accept CSV input paths, perform basic feature engineering, and save serialized prototype artifacts into `artifacts/`.
