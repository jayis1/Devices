# WasteSort Schematics

These are starter KiCad-style schematic text files intended to capture the primary electrical architecture for each node:
- `hub/hub.sch`
- `countertop-sorter/countertop-sorter.sch`
- `bin-dock/bin-dock.sch`
- `pickup-beacon/pickup-beacon.sch`

Each sheet lists the major ICs, rails, and critical interfaces so the design can be imported or redrawn into a full KiCad project.
