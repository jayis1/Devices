# FoodAllergySync ML Pipeline

Included training scripts:
- `train_label_parser.py`
- `train_cross_contact_risk.py`
- `train_strip_quant.py`
- `train_lunchsafe_forecast.py`
- `train_readyguard.py`
- `train_exposure_timeline.py`

These scripts generate baseline models from synthetic or curated household food-allergy datasets and demonstrate the feature engineering pipeline used by the edge/cloud stack.
