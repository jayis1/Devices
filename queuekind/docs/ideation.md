# Ideation and differentiation

Candidates considered:

- Community cold-chain food donation monitor: rejected because PantryLink and FoodAllergySync already occupy adjacent food-access/safety space.
- Public library seat availability: rejected because LibraryLoop already covers that purpose.
- Walk-in service wait estimates: selected because it addresses queue uncertainty with a distinct mechanism—anonymous doorway counts combined with explicit service completion—and does not track people or automate priority.

Value rubric (1–5, qualitative hypothesis; must be tested with users): frequent pain 4; severity 3; benefit visible within first week 5; installation friction 4; BOM affordability 4. Sum 20/25. No evidence of market demand or measured time savings is claimed. Validate with a supervised site pilot before expanding features.
