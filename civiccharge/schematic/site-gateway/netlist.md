# Gateway conceptual interface — not a PCB schematic

- Raspberry Pi Zero 2 W (40-pin header), powered by certified USB-C 5V/2.5A supply.
- BLE 5.0 integrated radio talks to monitor nodes; optional Ethernet adapter via USB OTG.
- No mains sensor or relay connects to gateway GPIO.
- Local SQLite storage on quality microSD; optional UPS is out of scope.

Production enclosure, supply certification, radio antenna clearances and thermal validation remain open.
