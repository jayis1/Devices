# Electrical design status

This directory intentionally does not claim to contain KiCad schematics. The design is presently a block/pin concept only; no fabrication outputs or electrical-rule-check results exist. Candidate ESP32-C3 module GPIOs and USB/LDO circuits are described in the project README and BOM, but must be checked against the exact module datasheet and carrier before a schematic is released. A gateway block diagram would likewise not constitute a connected circuit. Do not fabricate boards from these notes.
