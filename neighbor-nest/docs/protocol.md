# BLE observation protocol v1

Little-endian fields: version u8 (=1), node_id u16, sequence u16, kind u8 (1=soil, 2=visit, 3=health), payload_len u8, payload (0..20 bytes), CRC16-CCITT u16 over preceding bytes. Maximum frame length 29 bytes. Soil payload: ADC raw u16, temperature centi-degrees signed i16, relative humidity centi-percent u16, battery mV u16. Visit payload: button index u8 and flags u8. Health payload: flags u16. Units are explicit; missing values use documented node-side flags, not fabricated zero readings. Receiver rejects unknown versions, oversized frames, invalid CRC, and duplicate sequence numbers within a pairing session. CRC detects accidental corruption only; it is not authentication or encryption. Pairing and BLE bonding are required for deployment; rotate bonds on ownership change. No command frames are defined.

Transport: BLE advertisement for small telemetry; hub timestamps reception. BLE loss is tolerated; next periodic observation supersedes missed soil data. Check-in events may be lost while hub is unavailable; dock must show no confirmation until hub acknowledgement is implemented. The current sample firmware is interface scaffolding and does not yet implement a full radio stack.
