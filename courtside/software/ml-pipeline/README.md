# ML pipeline status

No ML is used: with no consented, representative labeled court observations, training a classifier would create unsupported performance claims. The baseline is explicit threshold+freshness triage (wetness threshold calibrated per surface; stale after 30 min). If later evaluating ML, collect staff-confirmed surface observations with site consent, document weather/surface labels and split by site and date to prevent leakage; compare precision/recall and calibration against this rules baseline before deploying. Never infer safety/playability.
