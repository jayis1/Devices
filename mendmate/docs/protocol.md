# Protocol v1

Transport prototype: MQTT on trusted private LAN; TLS and per-device publish ACLs are mandatory deployment work, not implemented here. Topic `mendmate/v1/<device_id>/telemetry`. JSON envelope: `schema` (exactly `mendmate.telemetry.v1`), `device_id`, `boot_id`, unsigned `seq`, UTC `observed_at`, `kind`, `payload`. Device IDs are provisioned locally; no production provisioning code is supplied. Consumer deduplicates `(device_id,boot_id,seq)` and rejects unknown schema, malformed values, oversized payloads (>1 KiB), unknown kind, and stale timestamps (>24h) where wall clock is available.

Kinds: `swatch` payload `{channels:[11 integers 0..65535], fabric_label?:string}`; channels are raw relative sensor counts and are not color/material measurements. `station` payload `{thread_cg:integer 0..500000, drawer_open:boolean}`. Sequence is per boot session and starts at zero. Sampling is button-triggered for swatch; station reports on a 30-second interval or drawer edge. MQTT QoS 1 may duplicate; receiver dedupe is required. No command topics exist. On hub outage nodes hold at most 64 telemetry events, then discard oldest; stale state is explicitly surfaced. Current C wire codec uses binary packet framing for node-unit tests; mapping binary packets to MQTT JSON remains an adapter boundary.
