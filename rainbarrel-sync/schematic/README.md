# Schematic status

This directory contains preliminary connection intent only. No KiCad schematic, PCB, ERC, DRC, or manufacturing package is provided; therefore these are not fabrication-ready. Before creating boards, select exact module/sensor variants and verify datasheets, GPIO strapping, echo voltage, supply transients, RF matching, connector protection, and enclosure ingress protection. Pin mappings in the system README are candidate mappings, not validated net assignments.
