# CleanSync ML Pipeline

This directory contains lightweight training scripts that generate synthetic home-cleaning datasets and export example artifacts.

Models included:
- `train_dirtcast.py` - room dirt-buildup forecaster
- `train_grimenet.py` - residue classifier from optical features
- `train_routebandit.py` - cleaning-window policy learner
- `train_sliprisk.py` - wet-floor hazard classifier
- `train_supplyflow.py` - detergent depletion forecaster
