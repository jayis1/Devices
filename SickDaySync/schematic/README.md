# SickDaySync schematics

This directory contains KiCad 8 `.kicad_sch` source files for each hardware node.

- `care-hub.kicad_sch`
- `recovery-band.kicad_sch`
- `room-sentinel.kicad_sch`
- `med-station.kicad_sch`
- `vent-controller.kicad_sch`

The sheets capture the principal ICs, interfaces, power rails, and wiring intent needed to start full PCB entry.
