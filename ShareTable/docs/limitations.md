# Limitations and operations

No recipient-level tracking, allergy inference, automated disposal, food-safety certification, temperature-control actuation, or trained ML model. Establish site retention/deletion policy before collection; default recommendation is 30 days, then delete or export aggregate counts. Obtain volunteer consent and post a clear notice. Use paper fallback during faults. Inspect probe, load cell, enclosure and cables before each service; compare probes with a calibrated reference on the operator’s schedule. Never use this prototype as the sole safety record.
